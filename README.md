# Book Inventory App

## Project Description

This project is a **Book Inventory App** created using HTML and CSS. It displays a list of books in a table and shows the author, category, reading status, and personal rating for each book.

The project was created as part of my HTML and CSS practice, especially to learn how to use **CSS attribute selectors, gradients, tables, and different classes** to style elements.

## Technologies Used

* HTML5
* CSS3

## Features

* Displays a book inventory in a table.
* Shows the book title, author, category, status, and rating.
* Books can have three different statuses:

  * Read
  * To Read
  * In Progress
* Uses different background gradients for each reading status.
* Uses rating indicators from one to three.
* Highlights the current reading information.
* Uses CSS attribute selectors for styling.
* Includes accessible text using screen-reader-friendly elements.

## What I Learned

While working on this project, I practiced:

* Creating tables using HTML.
* Using `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`.
* Using classes to represent different book statuses.
* Using CSS attribute selectors such as `[class="read"]` and `[class~="one"]`.
* Creating linear gradients with CSS.
* Styling elements based on their classes and attributes.
* Using nested `<span>` elements to create rating indicators.
* Using `inline-block` to control the layout of elements.
* Applying basic accessibility techniques.
